# Cidade em Foco

Portal web de denúncias de problemas urbanos. Os moradores registram
ocorrências (buracos, iluminação, lixo, vazamentos e outros), anexam fotos,
informam a localização e acompanham o andamento. Os administradores
visualizam todas as ocorrências, alteram status e consultam relatórios.

## Tecnologias

- **Backend:** Python, FastAPI, SQLAlchemy, Pydantic, SQLite
- **Frontend:** Angular, TypeScript, HTML, CSS
- **Mapa:** Leaflet e OpenStreetMap

## Estrutura do projeto

- `backend/` — API em Python (regras de negócio e banco de dados)
- `frontend/` — Site em Angular (telas que o usuário vê)
